# Express Server

A lightweight Express.js server example for the payfast-tools project.

## Quick Start

```bash
npm install
npm start
```

The server will run on `http://localhost:3000`

## Features

- Express.js setup
- Basic routing
- Middleware configuration

## File Structure

```
express/
├── index.js
├── package.json
└── readme.md
```

## Configuration

Update your environment variables in `.env` before running.
